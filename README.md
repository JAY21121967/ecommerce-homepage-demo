# 🛍️ Responsive E-Commerce Homepage Demo

A modern, responsive **e-commerce homepage template** built with **Tailwind CSS**.  
This demo showcases a clean online store design, including hero banner, featured products, categories, testimonials, and newsletter signup.  

🔗 **Live Demo:** [View on GitHub Pages](https://jay21121967.github.io/ecommerce-homepage-demo/)  

---

## ✨ Features
- 🎨 Modern, clean homepage design
- 📱 Fully responsive (mobile, tablet, desktop)
- 🛒 Featured products grid
- 📂 Categories section (Men, Women, Accessories)
- ⭐ Customer testimonials
- 📩 Newsletter signup
- ⚡ Fast-loading, SEO-friendly structure
